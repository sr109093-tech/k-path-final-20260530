# \## 🌟 앱 소개

# \*\*K-Path\*\*는 일상적인 산책부터 전문적인 등산까지, 사용자의 경로를 정밀하게 기록하고 안내하는 GPS 트래킹 애플리케이션입니다. 고정밀 지형 지도와 음성 안내 기능을 통해 안전하고 즐거운 운동 환경을 제공합니다.

# 

# \---

# 

# \## 🕹️ 주요 기능 가이드

# 

# \### 1. 메인 홈 화면

# \- \*\*4분할 운동 모드:\*\* 걷기, 등산, 자전거, 달리기 중 원하는 활동을 선택하여 즉시 시작할 수 있습니다.

# \- \*\*통계 요약:\*\* 중앙의 원형 대시보드에서 총 누적 거리와 기록 횟수를 한눈에 확인하세요.

# \- \*\*기록 보관소:\*\* 중앙 원을 터치하면 과거의 운동 경로와 상세 데이터를 다시 볼 수 있습니다.

# 

# \### 2. 고정밀 지도 및 트래킹

# \- \*\*지도 전환 (일반/위성):\*\* 우측 하단의 버튼으로 건물 번호가 보이는 세밀한 \*\*일반 지도\*\*와 지형지물이 보이는 \*\*실사 위성 지도\*\*를 자유롭게 전환하세요.

# \- \*\*실시간 경로 표시:\*\* 이동 중인 경로가 지도 위에 굵은 빨간색 선으로 표시되어 길 찾기가 쉽습니다.

# \- \*\*편의 아이콘:\*\* 현재 위치 찾기(📍), 사진 촬영(📷) 기능을 지도 위에서 바로 사용할 수 있습니다.

# 

# \### 3. 스마트 알림 시스템

# \- \*\*500m 음성 안내:\*\* 500m 이동 시마다 현재 주행 거리와 속도를 음성으로 알려주어 폰을 보지 않고도 운동에 집중할 수 있습니다.

# \- \*\*다국어 지원:\*\* 한국어는 물론 영어(English) 모드를 지원하며, 선택한 언어에 맞춰 UI와 음성 안내 언어가 자동 변경됩니다.

# 

# \---

# 

# \## ⚙️ 설정 및 사용자 관리

# 우측 상단의 \*\*톱니바퀴(⚙️) 버튼\*\*을 통해 앱을 개인화할 수 있습니다.

# 1\. \*\*사용자 설정:\*\* 아이디, 이름, 나이, 체중을 입력하고 프로필 사진을 등록하세요. 사진은 홈 화면 우측 상단에 표시됩니다.

# 2\. \*\*언어 설정:\*\* 한국어/영어 중 선호하는 언어를 선택하세요.

# 3\. \*\*알림 설정:\*\* 음성 안내 기능을 끄거나 켤 수 있습니다.
